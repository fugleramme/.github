# Fugleramme

Community-made projects related to [Fugleramme](https://github.com/arnegiacomo/fugleramme): real-time bird detection by audio, fully local AI, rendered as real, hand-cut 1800s bird illustrations.

See it live at **[fugleramme.arnegiacomo.dev](https://fugleramme.arnegiacomo.dev)**. Just want the standard setup? Start at the [main repo](https://github.com/arnegiacomo/fugleramme).

## Projects

- **[clients](https://github.com/fugleramme/clients)** - programs that show Fugleramme on other devices. Got an old tablet, a spare screen, a projector or a microcontroller with a display? Make it show your birds, then [open a pull request](https://github.com/fugleramme/clients/blob/main/CONTRIBUTING.md) to add your program (no need to ask first). Once it's merged, you join the maintainers and help look after the repo. [The docs](https://arnegiacomo.dev/fugleramme/screens/) help you get started.

## Get involved

- Have a new project that belongs here? [Start a discussion](https://github.com/arnegiacomo/fugleramme/discussions) on the main repo. Everything here is built and looked after together.
- Found a bug in one of the projects? Open an issue in its repo. A bug in the core project itself goes in the [main repo](https://github.com/arnegiacomo/fugleramme/issues).
